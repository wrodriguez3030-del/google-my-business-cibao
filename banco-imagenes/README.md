# Banco de imágenes

Deja aquí las fotos que se irán publicando en el perfil de Google Business. La cola las publica en orden (por carpeta y nombre) y nunca repite una ya publicada.

## Organización

```
banco-imagenes/
├── general/          → fotos válidas para cualquier sucursal
└── <sucursal>/       → una carpeta por sucursal (se crean en la Fase 2,
                        cuando Windsor diga cómo se llama cada ubicación)
```

## Reglas de las fotos (las exige Google)

- **JPG o PNG**, mínimo **250×250 px** y **10 KB** (recomendado: 1200×900 o más).
- Nombre en kebab-case y descriptivo — el nombre del archivo es la única pista que verá quien publique: `cabina-laser-sucursal-centro.jpg`, `fachada-letrero-noche.jpg`, `equipo-recepcion.jpg`.
- Prefijo opcional de categoría para que `/gmb-semana` la clasifique sin preguntar: `interior-...`, `exterior-...`, `equipo-...` (TEAMS), `trabajo-...` (AT_WORK). Sin prefijo → ADDITIONAL.
- Fotos reales del negocio, con buena luz. Nada de bancos de imágenes genéricos: Google los detecta y no aportan.
- Si sale una clienta reconocible: solo con consentimiento firmado.

## ⚠️ Este repo tiene un espejo público

Las fotos se sirven por `raw.githubusercontent.com` (Google exige URL pública). Todo lo que entre aquí queda visible en internet: solo material apto para publicarse.
